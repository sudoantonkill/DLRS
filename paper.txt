# Project Context Summary: Decentralized Land Registry System with Mumbai Map Integration

---

## Executive Summary / Overview

This project addresses the inefficiencies, opacity, and risks of fraud in traditional land record management systems by combining **Ethereum Smart Contracts (Sepolia Testnet)**, **Decentralized Authentication (Supabase)**, **Web3 Wallet Integration (MetaMask)**, and **Geographic Information Systems (GIS)** via **Leaflet OpenStreetMap**. The system enables tamper-proof land ownership registration, direct peer-to-peer property transfers, real-time title verification, and interactive map-based spatial inspection of real property plots (specifically mapped to Mumbai locations like Bandra West, Nariman Point, Andheri East, etc.).

---

## 1. Introduction

### 1.1 Problem Definition

Traditional land registry systems rely on centralized paper records or siloed electronic databases managed by government authorities. Key problems include:

* **Vulnerability to Fraud:** Centralized records can be altered, forged, or deleted by insider threats or unauthorized tampering.
* **Double Selling & Disputes:** A single property is often sold to multiple buyers due to delayed database updates or lack of real-time provenance tracking.
* **Lack of Transparency & Efficiency:** Title verifications require lengthy manual searches through land revenue records, involving intermediaries and high overhead costs.
* **Disconnection between Geographic and Legal Data:** Geographic land plots are rarely tied dynamically to on-chain legal ownership contracts in standard web applications.

### 1.2 Aim and Objectives

* **Aim:** To develop a transparent, tamper-proof, and spatially integrated decentralized land registration and management system using Ethereum blockchain and interactive GIS web mapping.
* **Objectives:**
1. Write and deploy an immutable smart contract (`LandRegistry.sol`) on the Ethereum Sepolia Testnet for land registration and ownership transfer.
2. Implement secure user authentication using Supabase DB to manage user roles and sessions.
3. Integrate Web3 wallet connectivity via MetaMask (`ethers.js` v6) for executing signed blockchain transactions.
4. Embed an interactive **Leaflet / OpenStreetMap** interface centered on Mumbai to visualize real property coordinates (lat/long) and query on-chain property data live upon clicking map markers.
5. Provide search and retrieval mechanisms for verifying property titles by unique Land ID.

## 2. Review of Literature

### 2.1 Literature Survey

Existing research emphasizes replacing central databases with distributed ledger technology (DLT) in government registry workflows. Early studies demonstrate that Ethereum's non-fungible token (NFT) standards (ERC-721) or key-value mappings can eliminate title deed tampering. Recent literature highlights integrating GIS layers (OpenStreetMap/Leaflet/GIS shapefiles) directly into Web3 applications to give visual context to physical assets.

### 2.2 Summarized Findings

1. **Blockchain guarantees immutability:** Once an ownership record is mined on-chain, it cannot be modified without consent from the key-holder.
2. **Web3 wallet execution ensures non-repudiation:** Transactions require cryptographic signatures via MetaMask, eliminating unauthorized property transfers.
3. **Map-based verification enhances user experience:** Linking geographic coordinates (latitude and longitude) with unique smart contract Land IDs allows non-technical buyers to inspect spatial boundaries alongside title status.

## 5. Methodology

### 5.1 Introduction

The methodology combines Agile web development with smart contract life cycle management (solidity compilation, deployment, and RPC interaction).

### 5.2 Key Methodological Steps

```
+-------------------+     +---------------------+     +-----------------------+
|  1. Auth & Login  | --> | 2. Connect MetaMask | --> | 3. Map Inspection /   |
|   via Supabase    |     |   (Sepolia Chain)   |     |    Query Blockchain   |
+-------------------+     +---------------------+     +-----------------------+
                                                                  |
                                                                  v
+-------------------+     +---------------------+     +-----------------------+
| 6. Real-time Map  | <-- | 5. Transfer Ownership| <-- | 4. Register Land Plot |
| State Update      |     | (Current Owner Only)|     | (Location/Area/ID)    |
+-------------------+     +---------------------+     +-----------------------+

```

1. **Authentication:** User logs in via Supabase Auth (or uses the Demo Bypass).
2. **Web3 Connection:** User connects MetaMask to the Sepolia Testnet (`chainId: 0xaa36a7`).
3. **Map-Based Querying:** The interactive map loads real geographic pins in Mumbai (Bandra West, Nariman Point, Andheri East, Lower Parel, Powai, Juhu). Clicking a pin triggers `contract.lands(plotId)` via Ethers.js to pull title data directly from Sepolia.
4. **Registration:** Authorized users register new property records (`registerLand(id, location, area)`) through a signed blockchain transaction.
5. **Transfer:** Current owners execute `transferLand(id, newOwner)` to transfer property rights safely on-chain.

## 6. Implementation Details & Results

### 6.1 Introduction

This chapter explains technical implementation across the Smart Contract, Frontend UI, and Map components.

### 6.2 System Implementation

* **Smart Contract Logic (`LandRegistry.sol`):**
* Data structure `Land` stores `id`, `location`, `area`, and `owner`.
* Public mapping: `mapping(uint256 => Land) public lands;`
* Function `registerLand(uint256 _id, string _location, uint256 _area)` validates uniqueness and assigns `msg.sender` as owner.
* Function `transferLand(uint256 _id, address _newOwner)` verifies `msg.sender == lands[_id].owner` before transferring ownership.


* **React + Leaflet GIS UI:**
* Uses `MapContainer`, `TileLayer`, `Marker`, and `Popup` components from `react-leaflet`.
* Implements OpenStreetMap tile layers for Mumbai (`center={[19.0760, 72.8777]}`, `zoom={11}`).
* Handles Leaflet marker icon asset fixes for Vite compatibility (`marker-icon.png`, `marker-shadow.png`).
* Event handlers capture marker clicks to update `selectedPlot` state and fetch live blockchain data.



### 6.3 Results

* **Immutability:** Once registered, property details are readable directly from the Ethereum Sepolia chain.
* **Spatial Correlation:** Real-world Mumbai locations (e.g., Bandra West at `[19.0596, 72.8295]`) accurately reflect their corresponding smart contract ID (`#101`).
* **Security:** Ownership transfer attempts by non-owners fail at the EVM level with transaction revertion.
